# **RF08 \- Determinar o estado da conexão**  
O coletor deve classificar continuamente o estado da sua conexão com a pulseira em: conectado, desconectado e nao-encontrado. O estado conexao-fraca é decidido pelo coordenador, a partir do RSSI publicado pelo coletor (RF19).

Caso de Uso \- Determinar o estado da conexão

| Campo | Descrição |
| :---- | :---- |
| Identificador | UC08 |
| Nome | Determinar o estado da conexão |
| Ator principal | Coletor BLE |
| Pré-condição | Monitoramento em execução |
| Pós-condição | Estado da conexão atualizado e registrado |

    
**História de usuário:**  
Como coletor BLE, quero classificar o estado da minha conexão com a pulseira, para que o sistema saiba quando é necessário reconectar e o coordenador saiba quando iniciar o *handoff*.

**Critérios de aceitação:**

* O estado deve ser conectado enquanto a conexão GATT estiver ativa.  
* O estado deve ser desconectado quando a conexão for perdida.  
* O estado deve ser nao-encontrado quando a pulseira não for detectada na varredura (RF18).  
* Toda mudança deve ser registrada em *log* com *timestamp*.
