 # **RNF04 \- Tempo de *handoff***

| Campo | Descrição |
| :---- | :---- |
| Identificador | RNF04 |
| Nome | Tempo de *handoff* |
| Categoria | Desempenho |
| Descrição | A transferência da pulseira entre coletores deve ocorrer rapidamente, minimizando o período sem monitoramento. A lacuna de dados de um *handoff*, da desconexão da origem até o vencedor publicar o estado conectado, deve ficar em até 20 s; quando passar disso, o coordenador registra um aviso (RF06). |
